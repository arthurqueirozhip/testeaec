# Sistema de Cadastro de Usuários e Endereços 

Este é um sistema de linha de comando em **C#** e **.NET Core**. Gerenciamento de cadastro de usuários e seus respectivos endereços

# Funções

*   **Sistema de Autenticação**: Mecanismo de Login e Autocadastro 
*   **CRUD de Usuários**: Criação, consulta, atualização e exclusão de contas de usuários.
*   **CRUD de Endereços**: Gerenciamento de múltiplos endereços vinculados ao usuário autenticado, garantindo isolamento de dados.
*   **Integração com ViaCEP**: Preenchimento automático e inteligente de logradouro, bairro, cidade e UF através do fornecimento de um CEP válido.
*   **Exportação para CSV**: Geração de um relatório unificado no formato `.csv` cruzando os dados relacionais de usuários e endereços.
